Stake AI — App Concept & Tech Stack

Core Idea: Users deposit funds → AI agent automatically executes trades and staking decisions across stocks, crypto, and DeFi. The highlight is “Creme” — a clean, anonymized performance metric showing profit on top of the initial stake. All graphs and stats are generalized (no personal data ever shown).

Production Tech Stack (Next.js 15):

  • Frontend: Next.js 15 (App Router) + React 19 + Tailwind + shadcn/ui
  • AI Engine: OpenAI GPT-4o / o1 or xAI Grok API
  • Trading: Alpaca Markets (stocks) + CCXT + Binance (crypto & staking)
  • Data: Polygon.io + CoinGecko / Binance WebSocket
  • Backend/Database: Next.js API Routes or FastAPI + PostgreSQL/Prisma
  • Auth & Hosting: NextAuth/Clerk + Vercel + Railway

Account Setup: Create accounts on Alpaca, Binance, OpenAI/xAI, and Polygon.io. Generate API keys and store them securely in .env. This demo uses seed data. In production the graph fetches live aggregated Creme data from the backend.

Flickering background starts automatically after ~10 seconds (randomized delay).
This is a self-contained demo. Copy-paste into index.html to test.
